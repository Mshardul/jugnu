# Tickets

Lightweight future-work tracker — one row per ticket, not a full spec. A ticket captures intent, why it was split out, and any concrete findings that seeded it, so nothing gets lost between now and whenever it's picked up.

When a ticket is ready to start: brainstorm → write a real spec under [`docs/architecture/`](architecture/README.md) → mark this row **Done** with a link to that spec in Remarks.

Status is one of: **Not started**, **In progress**, **Done**, **Dropped**. Use **Dropped** — never **Done** — when a ticket is closed without being built: superseded/merged into another ticket, made moot, or found to be a duplicate. Always say why, and point at the surviving ticket, in Remarks.

| 0077 | Deterministic exact-command addressing in the palette | Today's palette (`Fuzzy.swift` / `PaletteView.runSelection`) is pure fuzzy subsequence scoring with no exact-match floor — Return-without-selecting always fires `displayed[0]`, the current top fuzzy score, which is not guaranteed to be the command a user has in mind and can shift as the catalog grows (installing more addons can silently change what a previously-reliable query resolves to). Violates the command-palette promise that typing a command's exact name should deterministically run that command, the way a shell always runs the exact binary you typed (same principle raised while naming [0074](tickets.md)'s Audio commands). Fix: each command may declare a short, stable, catalog-unique **alias** distinct from its fuzzy-searched title/keywords; an exact (case-insensitive, full-string) alias match short-circuits ranking and runs that command directly — rule is **"if the typed text exactly matches a command's alias, run it; otherwise execute the first fuzzy suggestion"** (today's existing behavior, unchanged as the fallback). Aliases must be distinct enough to be *understood*, not just technically unique strings — near-synonym aliases across unrelated addons defeat the point. Fuzzy search stays the discovery layer for partial/remembered-fragment typing; alias is the deterministic address layer.
