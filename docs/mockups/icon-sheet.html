Jugnu icon sheet

Reference for ticket 0051 (epic 0068). Base glyphs: Lucide v1.45.0, unmodified paths. Jugnu layer: rounded tile + theme-tinted stroke + a warm ember glow (bloom around the glyph itself, not a separate shape) on every icon, every state — the glow is the family mark; state is read from which glyph is drawn (e.g. star vs star-off). Sizes: 16 / 26 / 34px — the shell's real menu-bar / result-row / favorite-tile sizes.

On/off = two distinct Lucide glyphs (star / star-off), not an outline/fill toggle — matches the rule locked for stateful icons generally (e.g. mic/mic-off). The glow appears on both states (dimmer on "off", matching its lower-contrast stroke) — state is read from which glyph is drawn, never from the glow.
